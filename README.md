# ResHub

A full-stack student accommodation and residence management web application built with a **React** frontend and a **Flask** REST API backend.

🔗 **Live Demo:** [reshub-101.vercel.app](https://reshub-101.vercel.app/)

## My Role & Contributions (Backend Infrastructure Engineer)
- Architected the core Flask application structure (`run.py`, `config.py`) and dependency management (`requirements.txt`).
- Configured database migrations using **Flask-Migrate / Alembic** and set up dual-environment database routing (local SQLite and cloud PostgreSQL).
- Assisted with backend API routing, email verification workflows, and cloud deployment configurations (`render.yaml`).

## Tech Stack
- **Frontend:** React, JavaScript, HTML/CSS (Deployed on Vercel)
- **Backend:** Python, Flask, SQLAlchemy, Flask-Migrate (Deployed on Render)
- **Database:** PostgreSQL (Production) / SQLite (Local Development)
